# Digitify — Handwritten Digit Recognizer

Digitify is a web-based handwritten digit recognition system powered by a Convolutional Neural Network (CNN). Users can draw a digit directly on the browser canvas, and the trained CNN analyzes the drawing and predicts the corresponding digit in real time.

## Features

* Handwritten digit recognition from `0–9`
* CNN trained on the MNIST dataset
* Interactive HTML5 drawing canvas
* Mouse and touch support
* Real-time prediction through a Flask API
* Prediction confidence score
* MNIST-compatible image preprocessing
* Animated prediction result
* Responsive single-page interface
* Himalayan visual background with a custom UI

## How It Works

```text
User Draws Digit
       ↓
HTML5 Canvas
       ↓
Image Preprocessing
       ↓
Grayscale + Resize + Normalize
       ↓
28 × 28 × 1 Image
       ↓
CNN Model
       ↓
Digit Prediction
       ↓
Confidence Score
       ↓
Result Display
```

## CNN Model

The model uses a convolutional neural network designed for MNIST digit classification.

```text
Input: 28 × 28 × 1
        ↓
Conv2D + ReLU
        ↓
MaxPooling
        ↓
Conv2D + ReLU
        ↓
MaxPooling
        ↓
Flatten
        ↓
Dense
        ↓
Dropout
        ↓
Dense(10) + Softmax
```

The model is trained using the MNIST handwritten digit dataset and saved as:

```text
models/digit_cnn.keras
```

## Installation

Clone the repository and open the project directory:

```bash
git clone <your-repository-url>
cd digitify
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Train the CNN

Run:

```bash
python train_model.py
```

The training script downloads the MNIST dataset, trains the CNN, evaluates it on the test set, and saves the trained model inside:

```text
models/digit_cnn.keras
```

## Run the Application

Start the Flask server:

```bash
python app.py
```

Open the application in your browser:

```text
http://127.0.0.1:5000
```

Draw a handwritten digit on the canvas and click **Predict**.

## API

### `GET /`

Loads the Digitify web application.

### `POST /predict`

Receives the drawn image, preprocesses it into MNIST-compatible format, and returns the CNN prediction.

Example response:

```json
{
  "prediction": 5,
  "confidence": 0.987
}
```

The prediction and confidence values are generated by the trained CNN and are not hardcoded.

## Testing

Run the automated tests with:

```bash
python -m pytest tests/test_app.py
```

The tests verify the Flask application and prediction endpoint.

## Dataset

Digitify uses the **MNIST handwritten digit dataset**, containing grayscale images of handwritten digits from `0` to `9`.

Each image is represented as:

```text
28 × 28 pixels
```
